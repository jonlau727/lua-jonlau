# lua-jonlau

SimpleAntiCheat is a basic Paper / Spigot Minecraft anti-cheat plugin.

## What it does
- Detects suspicious speed movement.
- Detects illegal flight toggles.
- Detects players staying in the air too long without a valid reason.
- Bans detected cheaters for **2 days** with the cheat reason included in the ban message.

## Build
```bash
mvn package
```

## Output
The built plugin jar will be placed in `target/`.
